API & Token

Gunakan token ini untuk mengakses API dari aplikasimu

🔑 API Token Kamu

••••••••

⚠️ Token adalah rahasia — siapa pun yang memegangnya bisa mengirim pesan dari nomor kamu.

📖 Contoh Penggunaan

Kirim teks:

curl -X POST {BASE}/api/send \ -H "Authorization: Bearer TOKEN_KAMU" \ -H "Content-Type: application/json" \ -d '{"target":"628xxxxxxxxxx","message":"Halo dari API!"}'

Kirim file (gambar/video/audio/dokumen):

curl -X POST {BASE}/api/send \ -H "Authorization: Bearer TOKEN_KAMU" \ -F "target=628xxxxxxxxxx" \ -F "message=Ini dokumennya" \ -F "file=@/path/invoice.pdf"

Kirim media via URL:

curl -X POST {BASE}/api/send \ -H "Authorization: Bearer TOKEN_KAMU" \ -H "Content-Type: application/json" \ -d '{"target":"628xxx","media_url":"https://contoh.com/gambar.jpg","message":"Cek gambar ini"}'

Broadcast (maks 100 nomor, delay otomatis):

curl -X POST {BASE}/api/broadcast \ -H "Authorization: Bearer TOKEN_KAMU" \ -H "Content-Type: application/json" \ -d '{"targets":["628xxx","628yyy"],"message":"Promo spesial!"}'

Pesan terjadwal:

curl -X POST {BASE}/api/schedule \ -H "Authorization: Bearer TOKEN_KAMU" \ -H "Content-Type: application/json" \ -d '{"target":"628xxx","message":"Reminder rapat","run_at":"2026-10-10T09:00:00+07:00"}'
