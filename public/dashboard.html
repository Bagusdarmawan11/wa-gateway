Documentation

Complete API guide for developers

🚀 Getting Started

Synpera provides a REST API that lets you send and receive WhatsApp messages programmatically. Every request requires a device token, which you can find in the API & Token section.

Getting Started with Synpera API

Watch this tutorial to get up and running in 5 minutes

Base URL

https://your-synpera-domain.com

Authentication

Use your device token in the Authorization header for all API requests:

Authorization: Bearer syn_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

📤 Send Messages

POST/api/send

Send a text or media message to a single recipient.

// Request Body
{
  "target": "628123456789",      // required: number or group JID
  "message": "Hello!",           // required (if no media_url)
  "media_url": "https://...",    // optional: file URL
  "filename": "document.pdf"     // optional: override filename
}

// Success Response
{ "status": true, "target": "628123456789@s.whatsapp.net" }

How to Send Messages via API

Text messages, images, documents and more
POST/api/broadcast

Send a message to multiple recipients (max 100 per request). Runs in background.

// Request Body
{
  "targets": ["628123456789", "628987654321"],
  "message": "Hello everyone!",
  "delay_ms": 3000    // delay between each message (min 2000ms)
}

// Success Response
{ "status": true, "message": "Broadcast ke 2 nomor dimulai di background" }

📅 Schedule Messages

POST/api/schedule
// Request Body
{
  "target": "628123456789",
  "message": "Your scheduled reminder!",
  "run_at": "2026-12-01T09:00:00Z"   // ISO 8601 format
}

// Success Response
{ "status": true, "schedule_id": 42 }

⚠️ Rate Limits & Best Practices

To avoid WhatsApp bans, follow these guidelines:

✓ Use delay_ms >= 3000 between broadcast messages
✓ Don't send more than 100 messages per hour per device  
✓ Use human-like delays (3–10 seconds recommended)
✓ Avoid sending identical messages repeatedly
✓ Always get consent before messaging contacts
✗ Don't use for spam or unsolicited messages
