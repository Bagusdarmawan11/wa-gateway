Cara pakai API

Kirim pesan: POST /api/send

Header: Authorization: Bearer TOKEN_KAMU

Body JSON: {"target":"08123456789","message":"Halo!"}

Broadcast: POST /api/broadcast dengan {"targets":[...],"message":"..."}
Jadwal: POST /api/schedule dengan {"target":"...","message":"...","run_at":"2026-01-01T10:00:00Z"}
