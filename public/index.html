Pertanyaan yang Sering Ditanyakan

Masih ragu? Temukan jawabannya di sini.

Synpera adalah platform WhatsApp API gateway yang membantu kamu mengirim dan membalas pesan WhatsApp secara otomatis — cocok untuk notifikasi, chatbot, reminder, tagihan, OTP, dan broadcast.
Bukan. Synpera adalah layanan pihak ketiga yang independen dan tidak berafiliasi dengan WhatsApp maupun Meta. Penggunaan yang wajar dan sesuai kebijakan WhatsApp sangat disarankan.
Ya. Kamu menghubungkan nomor WhatsApp milikmu sendiri ke sistem, sehingga semua pesan terkirim atas nama nomor kamu — penerima melihatnya seperti pesan biasa dari kamu.
Tidak wajib. Nomor WhatsApp reguler maupun WhatsApp Business sama-sama bisa digunakan.
Teks, gambar, video, audio (termasuk musik dan voice note), serta dokumen seperti PDF, Excel, Word, dan ZIP — semuanya lengkap dengan caption.
Bisa. Kamu dapat melihat daftar grup yang diikuti nomor kamu langsung dari dashboard, lalu mengirim pesan ke grup tersebut lewat API.
Tidak ada batasan ketat dari sisi sistem. Namun untuk menjaga nomor kamu tetap aman, broadcast dibatasi maksimal 100 nomor per request dengan jeda pengiriman otomatis.
Bisa. Satu akun Synpera dapat mengelola hingga 5 device (nomor WhatsApp) sekaligus, masing-masing dengan token API dan pengaturan sendiri.
Keamanan adalah prioritas kami. Password akun disimpan dalam bentuk terenkripsi, token API digenerate secara acak, dan kamu bisa membatasi akses API dengan whitelist IP. Riwayat pesan juga dapat dihapus otomatis jika kamu mengaktifkannya.
Flow builder adalah fitur untuk merancang alur balasan otomatis secara visual — misalnya: jika pelanggan menulis "harga", balas dengan daftar harga; jika menulis "alamat", balas dengan lokasi toko. Semua tanpa coding.
Risiko ada jika mengirim spam atau pesan masif ke orang yang tidak mengenalmu. Untuk meminimalkannya: kirim hanya ke kontak yang relevan, gunakan jeda antar pesan, dan hindari broadcast berlebihan.
Sangat mudah — cukup panggil API kami dengan token device kamu dari bahasa pemrograman apa pun (PHP, Python, Node.js, dan lainnya). Contoh kode lengkap tersedia di dashboard setelah kamu mendaftar.
Tentu. Synpera dirancang untuk UMKM, startup, hingga perusahaan yang membutuhkan otomatisasi pesan WhatsApp yang andal dan mudah dikelola.
