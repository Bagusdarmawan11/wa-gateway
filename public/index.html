Cara Kerja

Mulai dalam 3 Langkah

Tidak perlu kartu kredit, tidak perlu konfigurasi rumit.

1

Daftar Akun

Buat akun gratis dengan nama, email, dan password. API token langsung dibuat otomatis.

2

Scan QR

Masuk dashboard, scan QR dengan WhatsApp kamu — seperti WhatsApp Web.

3

Kirim via API

Gunakan token untuk kirim pesan dari aplikasi PHP, Python, Node.js, atau apa pun.
